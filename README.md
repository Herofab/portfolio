# Umer Amin | Portfolio

Personal portfolio of **Umer Amin**, Full Stack Software Engineer (.NET + Angular) who builds with AI coding agents.

- Static site: a single `index.html` plus `assets/`, no build step
- Dark/light theme, responsive, no frameworks

## Run locally
Open `index.html` in a browser.

## Deploy
Netlify: drag this folder onto https://app.netlify.com/drop, or connect this repo with publish directory `/`.
