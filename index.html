// how I build with AI

AI agents, used like an engineer

Using AI isn't the hard part; making its output reliable is. Here's the workflow I use on real production codebases.

Spec the repo

I write AGENTS.md / CLAUDE.md specs covering the stack, folder rules, naming, error handling and a definition of done.

Plan first

Changes that touch several files go through a planning step and get approved before any code is written.

Specialised agents

Role-based subagents (planner, backend, frontend, reviewer) and reusable skills for scaffolding APIs, migrations and UI.

Verify every change

Builds, unit tests and regression suites run after each edit, with limits on self-correction so agents never loop.
